# 交互式关系图谱（D3.js版）
一款基于 D3.js v7 开发的可视化关系图谱，支持拖拽、缩放、悬浮提示等交互，适用于展示用户社交关系、游戏好友亲密度等场景。
作者：imgsr(桁数)
## 功能特性
- 🎨 渐变背景+精致UI，视觉效果友好
- 🖱️ 节点拖拽、画布缩放，交互体验流畅
- 💬 鼠标悬浮or直接点击显示详细信息（关系、等级、亲密度等）
- 🎯 自定义关系类型、颜色、节点间距
- 📱 自适应屏幕尺寸

## 快速使用
1. 克隆/下载代码到本地
2. 放到同一个目录里，先定位到该目录，然后用Python手动填写信息
3. 可自定义：
   - ①中心用户信息（昵称、头像、等级等）
   - (用户协议不让抓包，借助网易大神私聊区会加载好友图片，技术上是可以抓到图片包的，我用的是百度识图加聚合图床https://graph.baidu.com/pcpage/index?tpl_from=pc
   - 和https://www.superbed.cn/)
   - ②各关系下的好友列表
   - ③关系类型名称、颜色(进阶)

## 配置说明
| 配置项 | 说明 |
|--------|------|
| centerUser | 中心用户基础信息（昵称、头像、等级、性别、称号） |
| relationTypeMap | 关系类型映射（名称、颜色） |
| friendRelations | 各关系下的好友列表（id、昵称、头像、等级、性别、亲密度） |

## 技术栈
- D3.js v7（力导向图核心）
- HTML5 + CSS3（布局与样式）
- Vanilla JS（原生JavaScript交互）
